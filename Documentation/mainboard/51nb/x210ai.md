# 51NB X210AI

Meteor Lake replacement mainboard for the ThinkPad X200/X201 chassis
(Core Ultra 7 165H or 9 185H, DDR5 SO-DIMMs, two M.2 NVMe and a 2.5"
SATA bay, two USB-C with one Thunderbolt 4).

## Disabling Boot Guard

The X210AI ships with Intel Boot Guard enabled, so the CPU won't run
coreboot until it's disabled. The board is in manufacturing mode, so
Boot Guard's config isn't fused and lives in editable SPI flash, where
it can be changed.

You can check that Boot Guard can be disabled with:

```sh
setpci -s 00:16.0 0x40.l
```

An output of `90000255` means the board is in manufacturing mode. Every
X210AI seen so far ships this way.

You can disable Boot Guard via Intel's MFIT, but this isn't accessible
to most people (if you can find it, use it, see below), so a prebuilt
image is provided
[here](https://github.com/WheeledCord/coreboot-x210ai/releases). Back
up your chip, then flash it internally:

```sh
flashrom -p internal -r factory_backup.bin
flashrom -p internal -w x210ai-bootguard-disabled.bin
```

## Making an image with MFIT

If you would rather not flash a prebuilt binary, you can disable Boot
Guard on your own dump with MFIT. You need a version that supports the
Meteor Lake-P layout; this was done with MFIT 18.0.10.2285.

Decompose your factory dump to get its config as editable XML:

```sh
mfit.exe --decompose dump.bin --saveconfig config.xml
```

In `config.xml`, find `BtGuardProfileConfig` and change its value from
`Debug Profile` to `Boot Guard Disabled`, then rebuild:

```sh
mfit.exe --loadconfig config.xml --build dump_bgdisabled.bin
```

## Flashing

coreboot is built for the BIOS region only; the factory descriptor and
ME are left in place. Internal flashing from Linux on the running board
is the easiest route:

```sh
flashrom -p internal --ifd -i bios -N -w build/coreboot.rom
```

External flashing with an SPI programmer also works. The SPI chip is a
WSON-8 on the mainboard, circled here:

![SPI chip location](x210ai.png)

Back up the factory flash before writing anything.

## Status

Boots Linux with NVMe/SATA, WiFi, Bluetooth, Ethernet, ALC1220 audio,
internal eDP and external HDMI/DP, USB, and S3 resume all working.
Tested on the Core Ultra 7 165H with a 3000x2000 eDP panel.

Untested: TPM (Intel PTT is not enabled in this ME image),
Thunderbolt/USB4, and WWAN.
